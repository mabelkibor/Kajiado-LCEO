# Outputs

Generated by the model. **Git-ignored** — everything here is reproducible from
(code, config, input data), and committing it would invite stale results being
read as current ones.

| Directory | Contents |
|---|---|
| `tables/` | Settlement results, technology comparison, viability, priority plan, sensitivity and scenario sweeps |
| `figures/` | The four standard result figures |
| `maps/` | Quick-look settlement maps |
| `reports/` | `run_summary.json` — headline figures and full run provenance |
| `logs/` | Timestamped run logs |

Regenerate with `lceo run` and `lceo figures`. Column definitions are in
[`../docs/DATA_DICTIONARY.md`](../docs/DATA_DICTIONARY.md).

## Provenance

Every run writes package version, git revision, Python version, scenario, config
source list and seed into `reports/run_summary.json`. **Quote that block
alongside any figure or table used in the dissertation** — it is what makes a
number traceable back to the code and configuration that produced it.
